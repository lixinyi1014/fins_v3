## 2. 新发现并修正的两个问题

### 磁力计与IMU之间有板内旋转

[DJI官方INS例程](https://github.com/RoboMaster/Development-Board-C-Examples/blob/master/20.standard_robot/application/INS_task.c)中，BMI088到公共板坐标是Rz(-90°)，IST8310到同一坐标是单位矩阵。
本工程驱动输出保留传感器原始轴，因此此前将两者套同一矩阵不正确。现在在 `FusionConfiguration.cpp` 中复合板内换轴：

```text
R_imu_to_body = [-1  0  0; 0  1  0; 0  0 -1]
R_mag_to_imu  = [ 0 -1  0; 1  0  0; 0  0  1]
R_mag_to_body = [ 0  1  0; 1  0  0; 0  0 -1]
```

整板安装仍采用原版roll=-gyro_x、pitch=+gyro_y的约定。板内相对旋转已经确认，整板对机体的朝向问题见下一节。
回归把同一物理向量分别表达成官方BMI/IST原始坐标，经过生产配置变换后必须一致；三个基向量和一个斜向向量均通过。

### 新FRD偏航闭环分配符号反了

依据STEP的水平推进器轴线和原版W向前约定，以 `力矩 = 位置 × 推力` 检查新控制器。修复前正偏航误差产生同向力矩，属于发散方向；深度、横滚和俯仰检查通过。
现在 `FusedController.cpp` 的偏航列改为左组负Sign、右组正Sign，使正偏航误差产生负偏航力矩。不改端口、不改原手动运动预置、不改原增益数值。

| 检查 | 修正后结果，PWM比例单位 | 判定 |
|---|---:|---|
| 深度目标增加 | 向下合力 +218.00000 | 方向正确 |
| 正横滚误差 | 横滚恢复力矩 -21.61555 | 方向正确 |
| 正俯仰误差 | 俯仰恢复力矩 -11.34000 | 方向正确 |
| 正偏航误差 | 偏航恢复力矩 -49.42533 | 方向正确 |

这些不是牛顿或牛顿米测量，依赖用户指定沿用的原桨向/推力符号约定。实物推力曲线、机械装反、接线反向不能靠该计算排除。

## 3. 官方C板模型与安装孔比对

已下载并解析DJI官方完整C板STEP，同时读取官方手册和原理图/位号图。下载来源与SHA256记录在随验证归档保留的 `official-sources.json`。

| 项目 | 官方资料 | 仓库简化模型 |
|---|---|---|
| 外形 | 手册60×41×16.3mm | 包络61×42×15mm，轴顺序不同 |
| 孔距 | 36×36mm | 36×36mm |
| 孔径 | 2.5mm | 圆柱半径1.25mm |
| 定位特征 | 完整板件、外壳、螺钉 | 矩形实体和4个孔，无插座特征 |

四孔的机体坐标为(57,-35,9)、(57,1,9)、(93,-35,9)、(93,1,9)mm。
将官方孔位去中心、对齐长短边后，存在两个相差180°的正确旋转，四孔残差均小于1e-5mm。矩形块的长边及正方形孔阵列在180°旋转下不变，故**孔位匹配不能唯一决定插座朝前还是朝后**。
两份仓库总装的后盖还有既有180°差异，本次没有将其伪称为已消除。

结论：C板型号、包络、孔位以及板内IMU/磁力计相对轴已经核对；绝对装机朝向仍沿用原约定并保留 `TODO(IMU_INSTALLATION)`。
最小实操：推进器动力断开，VOFA看放平、压右侧、抬头时角度方向。只需看数值，无需用Keil读变量；对应步骤在首次上电文档。若方向不符，再依据实际板件朝向改安装矩阵，不能靠显示偏置遮盖。

官方来源：[C板完整STEP](https://rm-static.djicdn.com/tem/35228/mounting_the_board_type_c_asm%28202001072134%29.stp)、[用户手册](https://rm-static.djicdn.com/tem/35228/RoboMaster%20%20%E5%BC%80%E5%8F%91%E6%9D%BF%20C%20%E5%9E%8B%E7%94%A8%E6%88%B7%E6%89%8B%E5%86%8C.pdf)。

## 4. 质心/浮心按用户指定处理

采用四个压力接口中心的平均点作为工程几何参考中心，质心、浮心均取该点，二者偏置为0，不再要求你测这两个点。
这是一项明确建模假设，不是STEP给出的真实质量/排水体积分布。当前控制器以PWM为输出单位，不另外添加质心/浮心恢复力矩模型；原固定浮力PWM补偿保留，因此ON后仍可能立即有推力。
