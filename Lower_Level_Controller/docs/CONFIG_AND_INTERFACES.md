## 坐标与来源

机体前方为半球罩方向，机体右方为面朝前方时的右侧，z 向下，采用右手 FRD。
q_bn 是 Hamilton `[w,x,y,z]`，body→本次启动参考世界系，roll/pitch/yaw 单位 rad，角速度 rad/s，深度 m、压力 Pa。
磁场首次合格观测建立相对启动航向参考，沿用原代码 MAG_OFFSET/MAG_SCALE；不是地理真北。
场强或方向异常时拒绝更新；需要偏航闭环而磁场过期时停止。

### 压力口几何

本轮遍历 `Structure/zh-CN` 的19份STEP，以 `外形.STEP` 的装配变换确定外设位置。
压力传感器接口圆柱实体 #90932 对应局部参考点 `(2.452381722,8.974201395,15.415698431) mm`。
经四个装配变换，参考口沿中心间距为 249.4×138.2 mm；四口中心为机体原点。
支架原点的 225×138.2 mm 没有当成压力口位置。

| TCA | V3.3设计p7编号对应位置 | x / y / z（m） |
|---|---|---|
| 0 | 传感器1，前左 | +0.1247 / -0.0691 / 0 |
| 1 | 传感器2，后左 | -0.1247 / -0.0691 / 0 |
| 2 | 传感器3，后右 | -0.1247 / +0.0691 / 0 |
| 3 | 传感器4，前右 | +0.1247 / +0.0691 / 0 |

TCA顺序已由V3.3设计p7明确，替代此前从旧site推定的前后位置。
按用户2026-09-16要求，以连接口中心作为传感器位置，本几何项关闭，不再等待内部膜片偏移。数值与现有配置一致。
八个推进器、四个舵机轴、舱内板件坐标及两份总装的后盖差异，见 [STEP位置核对](CAD_GEOMETRY_20260916.md)。通道号依据原代码/设计图，STEP不提供电气接线证明。
压力口都至少约 5 cm 水头时才使用压差融合姿态；空气中由 IMU 估计姿态，四路压力仍提供深度均值。

### IMU 换轴

原程序采用横滚角速度 `-gyro_x`、俯仰 `+gyro_y`。当前采用原板 +Z 朝上的安装假设：
`R_imu_to_body = diag(-1,+1,-1)`，保持右手旋转，yaw 角速度因此为 `-gyro_z`。
比力转重力使用 -1。官方例程确认IST8310到BMI088原始坐标还有Rz(+90°)板内旋转，故 `R_mag_to_body = [0,1,0; 1,0,0; 0,0,-1]`，不能直接套IMU矩阵。
官方C板与简化模型孔距36×36mm、孔径2.5mm一致，但绕法线180°仍可匹配。TODO(IMU_INSTALLATION)：整板绝对朝向仍用原约定，首次用VOFA倾斜动作确认；偏置/磁场补偿先沿用原版。详见 [最终对接](FINAL_INTEGRATION_20260916.md)。
质心和浮心按用户要求共处四个压力接口平均几何参考中心，偏置=0；不另加质心/浮心恢复力矩模型。

## 当前新控制器

`FusedController.cpp` 为实际输出控制器。深度环及角速度环150 Hz，角度外环50 Hz，I/D 使用实际秒数。
旧速率环比例增益 roll/pitch/yaw=8/8/5；其他初值按 `Ki_new=Ki_old*f`、`Kd_new=Kd_old/f` 换算。
30BA 旧兼容刻度约为 Pa/2000（20°C 附近），再用 rho*g 和上述口沿几何换成米、弧度输入。
新控制的 pressure→Pa 已使用独立的 30BA 温补。

PWM 分配沿用原正反桨、通道和向下推力的脉宽符号。新 FRD 满足 `Mx=y*Fz, My=-x*Fz`，
因此新 pitch 列按“前上后下”为正生成，不能把原压差控制的全部符号直接复制进来。
本轮进一步按STEP水平轴线修正新yaw列为左组负Sign、右组正Sign；正偏航误差现在产生负恢复力矩。深度/横滚/俯仰/偏航四轴均通过CAD符号回归，仍以原桨向/推力约定为前提。
保留原版浮力/运动预置和最终限幅，死区按V3.3设计p9改为上下不对称补偿。TODO：换算仅是整定初值。

## 命令

| 命令 | 行为 |
|---|---|
| DIAG | 控制耗时、超期次数、收包丢弃、I2C错误、融合拒绝次数、温度、温控故障、停止原因 |
| STAT | 当前固定ESKF、停止/就绪/校准/故障标志及最后停止原因 |
| HB | 每约100 ms发送；只续期，不启动 |
| ON / OFF | 人工启动/停止；启动保持当前非负深度，目标横滚/俯仰在停止时清零 |
| W/A/S/D，Q/E，Z | 原水平移动、旋转及停止水平运动 |
| UP / DN | 目标深度每次减/加1 cm，UP最低0 |
| H:1000 | 目标深度1 m（原命令n/10 cm） |
| FSET:0.3,0,0,0 | 深度0.3m，横滚/俯仰/偏航目标0° |
| ACL:ON / ACL:OF | 偏航闭环开/关，默认关；开启时取当前航向为目标 |
| TES:v0,...,v7 | 完整8项、1000～2000 us的手动PWM，仅关闭闭环时使用，仍需有效反馈与心跳 |
| MOT:a,b,c,d | 原四路舵机命令 |
| VOFA:ON / VOFA:OFF | 开/关默认50Hz、16通道FireWater显示，不影响控制 |
| FLOG:ON / FLOG:OFF | 同VOFA开关，兼容别名 |
| CA | 停止并提示在空气中重新上电校准 |
| FB:ESKF | 回复OK，模式本来就是ESKF |
| FB:LEGACY / FB:SHADOW | 拒绝；交付版本不切回旧控制 |

VOFA显示顺序：roll_deg,pitch_deg,yaw_deg,depth_m,p0_m,p1_m,p2_m,p3_m,STOP,READY,CAL,RAW_MASK,FAULT,FUSED_MASK,FLAGS,SEQ。
每行以 `vofa:` 开头、CRLF结束，完整行作为一个192字节容量的消息入队，名义10Hz。
-9999表示缺测/过期；SEQ是16位显示包序号，断线后旧数据显示不能作为当前状态。
状态文本改用 `CAL= / CTRL= / STAT= / FB=`，避免冒号后非数字被FireWater误解析。命令里的冒号保持不变。
旧F/Q日志及旧四路兼容压力裸CSV不再从默认控制任务输出。内部ESKF仍为SI弧度，显示层转换为度。
详细接线、Keil操作和通道说明见 BOARD_BRINGUP.md。
STAT 中 READY=1 是软件当前反馈可用，不代表实际推进器已经转动或完成实机标定。
接收端跨IDLE拼接命令；CR或LF结束才执行，推荐CRLF。最长99字符，整行须在250ms内送完；超长、非法字节、超时或串口错误后丢弃到行尾。不再接受没有行尾的ON/OFF。所有运动/舵机目标要求当前停止代次且收包不超过500ms。
